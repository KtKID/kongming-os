## ② 精简技术设计

- D1：新增 `host/access-probe.ts`，Zod 定义唯一事件结构，白名单提取时间、事件、Host、socket 地址、浏览器说明及来源声明。Node 原生 HTTP 完成事件记录页面响应；密码结果直接来自原鉴权分支的通知，只有上游确实升级连接后记录实时连接开启，socket 关闭记录结束。原 JS 模块只增加可选观察回调，并隔离观察异常。覆盖场景1、2及 C1。
- D2：原生文件流独占新建 `0600` 临时文件，文件上限 5 MiB，待写入上限 64 KiB；每字段最多 512 字符，只保留来源声明中的合法地址。每条写入前检查流的待写量和文件预算；失败停用采集并只提示一次。关闭时等待流结束。覆盖场景3—5及 C1/C2。
- D3：默认关闭。插件加载时检查本机 `$DSH_HOME/kmh-remote/access-probe.enabled` 标记；标记存在才启用。输出位于现有临时目录，按次独占命名，启停只影响 Remote。构建只为新增 TS 模块添加 ESM 输出，扩展现有严格检查覆盖。覆盖场景1、5。
- 规范：R1 依赖单向，记录器只依赖 Node 与现有 Zod；R2 事件 schema 唯一；R3 单语言无需跨语言同步；R4 临时文件为事件唯一保存处；R5 统一 access-probe 命名；R6 具名容量常量；R7 原生流背压、错误隔离及生命周期回收。遵循 dev-ts、KMH 文档规范和 CI 测试可靠性规则。
