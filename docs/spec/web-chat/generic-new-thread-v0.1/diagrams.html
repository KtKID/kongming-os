时序

sequenceDiagram
  participant U as 用户
  participant FE as GenericEmptyThreadView
  participant API as /api/threads/generic/first-message
  participant TM as ThreadManager
  participant S as Session backend
  participant R as Generic runtime
  participant WS as /ws/threads/{thread_id}

  U->>FE: 点击通用加号
  FE->>FE: 写 pending generic 状态并渲染空白页
  U->>FE: 选择项目并发送第一句话
  FE->>API: POST text + preset_id + cwd
  API->>API: 解析请求并校验字段
  API->>TM: create_generic_thread_from_first_message
  TM->>TM: 生成 thread_id 并准备 metadata
  TM->>S: append Message.user(text)
  S-->>TM: append 成功
  TM->>TM: 写入业务可见 metadata
  TM->>R: 启动或排队后续 generic run
  TM-->>API: ThreadMetadata
  API-->>FE: ThreadMetadataDTO
  FE->>FE: fetchThreads + navigate /chat/{thread_id}
  FE->>WS: 打开现有通用 WS
  WS-->>FE: thread.history + 后续流式帧

状态

stateDiagram-v2
  [*] --> Idle
  Idle --> PendingGenericBlank: click generic plus
  PendingGenericBlank --> FirstMessageSubmitting: submit first message
  FirstMessageSubmitting --> ThreadCreated: metadata and user message persisted
  ThreadCreated --> ExistingGenericThread: navigate real thread
  FirstMessageSubmitting --> CreateFailed: validation or persistence failed
  CreateFailed --> PendingGenericBlank: keep draft input
  ExistingGenericThread --> [*]
