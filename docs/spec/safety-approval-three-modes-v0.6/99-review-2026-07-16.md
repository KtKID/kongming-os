## 核心目标一：审批规则从 setting.yaml 移到每个 thread 专属 — 完成

- `setting.yaml` 只剩 `approval_mode` + `auto_judge`（`src/infrastructure/config/models.py:816-850`），旧字段（approval_rules / trusted_workdirs / allow_writes / allow_tools_silent / permissions）已从 schema 移除，loader 遇旧字段报错并指向迁移脚本。
- 本子落盘 `<kongming_home>/safety/thread_permissions/<sha256(thread_id)>.json`：文件内 thread_id 回读校验、revision CAS、fsync + `os.replace` 原子写（`_thread_permissions_store.py`）。
- `PermissionsManager` 唯一门户（resolve / snapshot / write_entry / delete_entry / delete_thread / build_remember_expression），per-thread `asyncio.Lock`；跨模块无直接 import `_thread_permissions_store.py`（约束 20 满足）。
- thread 隔离验证到位：hash 路径防穿越、A/B thread 隔离、删 thread 编排本子清理 + 失败重试队列（`src/hosts/web/threads/manager.py:520-521`）+ 启动孤儿扫描（`threads/manager.py:2136` 调 `cleanup_orphans`）。
- remember 防篡改：pending 创建时冻结 thread_id / candidate / revision，前端 remember 退化为 bool，无法把规则写到别的 thread（resolve 链路双重校验）。

## 核心目标二：格式变成 allow + deny — 完成

- deny 先于 allow（`permissions_manager.py:118` 固定顺序），有专项单测。
- 旧体系删净：`guards/trust.py`、`grants/`、`boundaries/`、`rule_persister.py`、`approval_rule_manager.py`、`RuleSource` / `RememberScope` / `RuleScope` / `RuleBehavior.ASK` 全部不存在，全仓无残留 import，`.importlinter` 同步收紧。
- 迁移脚本 `scripts/migrate_permissions_v06.py`：必填 `--thread-id`、`--dry-run` / `--apply`、ask 规则丢弃、trusted_workdirs 只生成候选、幂等去重、禁止全 thread 扇出，均有单测（`test_migrate_permissions_v06.py`）。

## 三步决策链与 danger 层 — 完成

- `decision_engine.py` decide() 严格三步：DangerGuard.match → 模式开关 → thread 本子；thread 键解析 metadata["thread_id"] 优先、回落 session_id（`decision_engine.py:213-220`）。
- danger 在 full_trust 下仍强制审批（三模式参数化测试覆盖）；danger 命中 `remember_allowed=False`，不提供"记住"。
- DangerGuard 新增规则齐全：git-internal-write、agent-instruction-write（CLAUDE.md / prompts）、self-escalation 同时检测改 approval_mode 与扩大 thread permissions allow；destructive（rm -r* / shred / srm）并入。
- danger 元数据贯通：`consent.py:60` 写入 → web manager 读取 → inbox 帧 → 前端强红 + 禁 Enter + 隐藏"记住"（ApprovalToastCard，vitest 覆盖）。
- auto 模式 fail-closed 回落 user_approval + 告警事件；三处装配点（CLI / web run / approval_runtime_manager）注释断开并留 `# TODO(auto-mode)`，`src/safety/auto_approval/` 本体保留。
