关键约束（再次明确）

  1. safety 包 0 import web：broadcaster 通过 DI 在装配点注入；详见 10-architecture.md
  2. SDK can_use_tool sync 兼容：ApprovalBridge thin wrapper 仍持 Future 桥接（阶段 2 关键）；详见 60-risk #R3
  3. 双轨期 contract：阶段 1-2 共享 inbox_helpers + 等价性测试；详见 50-migration-plan
  4. 中文 docstring 强制：所有新建/改动函数必须中文 docstring（用户硬约束）；阶段 5 加 pre-commit hook 检查；详见 60-risk #R8
  5. 0 历史数据迁移：allow_list 是 per-process 内存重启就丢；阶段 2 无需迁移；详见 60-risk #R7
