# Docker 沙盒访问记录时区

## 问题与根因

宿主系统时区为 Asia/Shanghai，试用容器系统时区为 Etc/UTC。记录器通过 Date 的系统本地时间和 Intl 的系统时区生成 occurredAt、timeZone，因此容器写入的记录显示 +00:00。

## 修复

将当前沙盒系统时区同步至宿主系统的 Asia/Shanghai，并重启服务。忽略目录中的本地 Compose 覆盖配置设置 TZ，供后续重建使用；部署操作说明集中在该目录的 README。

记录器继续读取运行系统的时间与时区，记录格式保持原样。已有记录保留写入时的原始时间与时区。

## 验证

- 宿主系统和重启后的容器均返回 Asia/Shanghai、UTC+08:00。
- 通过实际密码校验入口提交一次错误测试密码，新增记录 occurredAt 为 2026-10-23T11:05:15.694+08:00，timeZone 为 Asia/Shanghai。
- 原有三条记录的原始字节指纹一致。
- 容器健康，端口映射保持调整前配置；本地 Compose 配置校验通过。
