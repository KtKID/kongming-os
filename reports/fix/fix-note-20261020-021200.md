# KMH Remote 局域网开关修复

2026-10-20，范围为局域网访问开关与对应回归验证。

局域网开关提交 `enabled`，宿主接口读取 `on`，导致开启操作被保存为关闭。接口返回 `{ lanEnabled }` 后，设置页又将它按完整状态校验，因此显示整组字段缺失错误。

`packages/kmh-remote/client/index.jsx` 的局域网开关提交 `on`，保存成功后读取 `pocket.status`，用完整状态刷新表单和二维码。`packages/kmh-remote/test/settings-actions.test.mjs` 使用构建后的客户端和真实 RPC 处理器，验证开启、关闭、字段传递及完整状态保留。包 README 说明该保存流程。

验证记录：聚焦用例在修复前复现状态校验错误；当前插件 138 项测试通过。独立浏览器实例完成局域网开关关闭、重新开启、二维码恢复及刷新后状态保留，验证实例随后关闭。构建完成。

frp 配置操作独立于局域网修复，插件的公网地址由用户填写。公网配置修复与用户手动验收结果见 [frp 转发配置修复记录](fix-note-20261020-113900.md)。
