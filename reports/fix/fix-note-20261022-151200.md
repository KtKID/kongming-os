# Remote 局域网密码开关修复

修复时间：2026-10-22 15:12（Asia/Shanghai）

## 现象与原因

在设置页或插件详情页开启局域网访问密码后，页面显示完整状态中多个字段缺失的校验错误。

客户端提交 `{ enabled: true }`，服务端根据 `payload.on === true` 保存开关，因此开启操作实际写入关闭。服务端返回 `{ lanAuthEnabled }`，客户端直接按照 `RemoteStatusSchema` 校验，导致 `proxyRunning`、端口及二维码等必填字段报错。手机右侧栏具有相同参数和响应问题，密码修改也返回操作专属结果。
